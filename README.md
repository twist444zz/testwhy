# BUS TIME 🚌

แพลตฟอร์มเช็กเวลารถเมล์มาถึง เส้นทาง ป้ายจอด และติดตามตำแหน่งรถเมล์แบบเรียลไทม์ **ทั่วกรุงเทพมหานครและปริมณฑล** บนแผนที่จริง (Leaflet + CARTO Dark Matter) ดีไซน์ Modern Dark Transit Glassmorphism แบบ Split View (ค้นหา/ข้อมูลซ้าย – แผนที่ขวา)

## เปิดดูเร็วที่สุด
เปิด `bustime.html` ในเบราว์เซอร์ (โหลด React/Leaflet จาก CDN) หรือใช้ **`bustime-offline.html`** (สร้างด้วย `npm run build:offline`) ที่ฝังทุกอย่าง (รวมฟอนต์) ไว้ในไฟล์เดียว **ใช้ได้โดยไม่ต่ออินเทอร์เน็ตเลย** – ไม่ต้องติดตั้งอะไร ไม่ต้องใช้ API Key

## เวอร์ชัน Desktop / Kiosk (Electron)
```bash
npm install
npm start          # หน้าต่างปกติ
npm run kiosk      # เต็มจอ Kiosk
npm run dist       # สร้างตัวติดตั้ง Windows (NSIS)
```
`npm run build:desktop` ดึง React/Leaflet/ฟอนต์มาไว้ในเครื่อง โค้ดไม่โหลดสคริปต์จากภายนอก และ CSP อนุญาตการเชื่อมต่อเฉพาะ `*.basemaps.cartocdn.com` (ภาพแผนที่) กับ `router.project-osrm.org` (เส้นทางถนน) เท่านั้น – **เครื่อง Kiosk ต้องมีอินเทอร์เน็ตเพื่อแสดงแผนที่**

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `bustime.html` | แอปทั้งหมด (React + htm + Leaflet): ค้นหาสาย/ป้าย, แผนที่จริง, ETA, ติดตามรถ, โปรด/แจ้งเตือน, แผงแอดมิน |
| `electron/main.js` | หน้าต่าง, IPC (รับเฉพาะจากหน้าหลักของแอป), ล็อกการนำทาง, Kiosk |
| `electron/preload.js` | เปิดเฉพาะ `window.bustimeSystem` ผ่าน contextBridge |
| `electron/system.js` | ล็อกอินแอดมิน (scrypt), allowlist คำสั่งระบบ, ตรวจและนำเข้า `.reg`, audit log |
| `registry/*.reg` | โปรไฟล์ Registry สำหรับ Kiosk (`kiosk-optimize.reg`) และย้อนกลับ (`kiosk-restore.reg`) |
| `scripts/build-offline.js` | สร้าง `bustime-offline.html` ไฟล์เดียวใช้ได้โดยไม่ต่อเน็ต |
| `test/` | `ui.test.js` (jsdom, 110 ข้อ) และ `system.test.js` (10 ข้อ) – รันด้วย `npm test` |

## แผงแอดมิน – สิทธิ์และความปลอดภัย
- ผู้ใช้ทั่วไปดูได้อย่างเดียว ไม่มีปุ่มแก้ไขใดๆ; Admin คนเดียวเพิ่ม/แก้/ลบสายรถ ป้าย พิกัด เส้นทาง และตารางเวลาได้ (ตรวจพิกัดต้องอยู่ในประเทศไทย, ห้ามลบป้ายที่ยังมีสายใช้อยู่)
- ครั้งแรกที่เปิดจะให้ตั้งรหัสผ่านแอดมินเอง (ไม่มีรหัสผ่านเริ่มต้น)
- **แผงระบบ (Registry / DNS / แคช / Kiosk) ใช้ได้เฉพาะในแอป Desktop** เบราว์เซอร์สั่งรันคำสั่งเครื่องไม่ได้ ปุ่มจะถูกปิด
- ไม่มีช่องพิมพ์คำสั่งเอง: renderer ส่งได้แค่รหัสคำสั่ง (`dns:flush`, `cache:clear`, `kiosk:on|off`, `optimize:all`) และชื่อไฟล์ `.reg` ที่มีอยู่จริงในโฟลเดอร์ `registry/`
- ก่อนนำเข้า `.reg` ระบบตรวจเนื้อหา: อนุญาตเฉพาะ `HKEY_CURRENT_USER`, ห้ามลบทั้งคีย์, ห้ามคีย์ `Run`/`RunOnce`/`Winlogon`/`Image File Execution Options`/`Services` (ถ้าจำเป็นต้องแก้ HKLM ตั้ง `BUSTIME_ALLOW_HKLM=1` และรันแอปด้วยสิทธิ์ผู้ดูแล)
- ต้องกดดูเนื้อหาไฟล์ก่อนจึงนำเข้าได้, ทุกคำสั่งมี audit log, เซสชันแอดมินหมดอายุใน 15 นาที
- จะเพิ่มโปรไฟล์ Registry ใหม่: วางไฟล์ `.reg` (ASCII หรือ UTF-16) ลงใน `registry/` แล้วรีสตาร์ทแอป

## แผนที่จริงทำงานอย่างไร
- **ภาพแผนที่ = เวกเตอร์ประเทศไทยในตัว (ไม่ใช้ไทล์ภายนอก):** Leaflet ทำหน้าที่ซูม/แพน แต่วาดพื้นแผนที่เองทั้งหมด (จังหวัด 77, ประเทศเพื่อนบ้าน, ทะเล/อ่าวไทย, แม่น้ำ, ถนน, สวนสาธารณะ, ป้ายชื่อ) เริ่มที่ฝั่งธนบุรี–เพชรเกษม `13.7115, 100.3885` ซูม 13 ปุ่มโฮมกลับจุดเริ่มต้น ปุ่มโลกดูทั้งเครือข่าย
- **เส้นทางตามถนน (ตัวเลือก):** ค่าเริ่มต้น **ปิด** = ไม่เรียกบริการภายนอกเลย เส้นสายรถเมล์ต่อตรงระหว่างป้าย (หรือใช้เส้นที่แคชไว้) กดปุ่ม "แนวถนนจริง (ออนไลน์)" ที่แถบตำนานเพื่อขอ geometry จาก OSRM (`router.project-osrm.org`, สำรอง `routing.openstreetmap.de`) สายละ 1 ครั้ง แล้วแคชใน localStorage (`bustime.roads.v1`)
- **ข้อมูลแผนที่ในตัว:** ขอบเขตจังหวัด/ประเทศ ถนนสายหลัก แม่น้ำ จาก UN OCHA / Natural Earth (โดเมนสาธารณะ/CC BY-IGO) + ขอบเขตเขต/อำเภอ กทม.-ปริมณฑล (69 พื้นที่) จาก chingchai/OpenGISData-Thailand (CC BY 4.0) + ถนนสายหลัก/สวนสาธารณะในกรุงเทพฯ ที่เขียนเอง (พิกัดโดยประมาณ ไม่ใช่ระดับสำรวจ) ใช้หา "เขต" ของป้ายเพื่อค้นหาด้วยชื่อเขตได้ เช่น `เขตจตุจักร`
- **ฟอนต์:** Google **Noto Sans** ทั้งระบบ (ตัวอักษรละติน/ตัวเลข) คู่กับ **Noto Sans Thai** สำหรับอักษรไทย เพราะ Noto Sans ไม่มีกลีฟไทย; ไฟล์ออฟไลน์/Desktop ฝังฟอนต์ไว้ในตัว (น้ำหนัก 400/500/600/700) เวอร์ชัน CDN โหลดจาก Google Fonts
- **ความทนทาน:** ไม่ขอไทล์/ฟอนต์/สคริปต์จากภายนอกในไฟล์ออฟไลน์ จึงไม่มี Error 403 หรือโควตา API; ฟอนต์ฝังไว้ในไฟล์
- **รถเมล์เคลื่อนที่:** ตัวจำลองคำนวณตำแหน่งตามระยะบนเส้นทางที่ได้ (ตามถนนเมื่อมี geometry) และเลื่อนมาร์กเกอร์แบบ linear ทุก 1 วินาที ETA/ระยะทางคำนวณตามระยะบนเส้นทางเดียวกัน
- **Pop-up ป้าย:** กดหมุดป้ายเพื่อดูชื่อ สถานี BTS/MRT สายที่ผ่าน และรถคันถัดไป
- **แอดมินปักหมุดป้ายใหม่:** แผงแอดมิน → ป้าย → เพิ่มป้าย → "เลือกพิกัดจากแผนที่" แล้วคลิกบนแผนที่จริง ระบบวางหมุดและใส่พิกัดให้ (จำกัดพิกัดในกรุงเทพฯและปริมณฑล)
- เซิร์ฟเวอร์ OSRM สาธารณะ (demo) มีข้อจำกัดการใช้งาน ถ้าใช้งานจริงจังควรตั้ง OSRM/Valhalla ของตัวเอง แล้วแก้ `OSRM_URL` ใน `bustime.html` และ CSP ใน `scripts/build-desktop.js`

## รถไฟฟ้า / วางแผนเส้นทาง / ธีม / คู่มือ

- **รถไฟฟ้า 10 สาย 173 สถานี:** BTS สายสุขุมวิท/สีลม/สีทอง, MRT สายสีน้ำเงิน/ม่วง/เหลือง/ชมพู, Airport Rail Link, SRT สายสีแดงเข้ม/อ่อน (ดู `RAIL_SEED` ใน `bustime.html`) วาดบนแผนที่ตามสีประจำสาย สถานีเชื่อมต่อ (Interchange) เป็นวงขอบดำ และแสดงป้าย “สถานีเชื่อมต่อ” ในรายการ
- **วางแผนเส้นทาง (แท็บ “วางแผน”):** เลือกต้นทาง/ปลายทางเป็นสถานีรถไฟฟ้าหรือป้ายรถเมล์ ระบบหาเส้นทางด้วย Dijkstra บนกราฟสถานี+ป้าย (ขึ้นสายใหม่ = รอครึ่งหนึ่งของความถี่ + ค่าปรับการเปลี่ยนสาย, เดินเปลี่ยนสถานี/ป้ายที่ใกล้กัน) ให้ทางเลือก เร็วที่สุด / เปลี่ยนต่อน้อยที่สุด / รถไฟฟ้าอย่างเดียว พร้อมจำนวนสถานี/ป้าย จุดเปลี่ยน เวลาโดยประมาณ และวาดบนแผนที่
- **ธีม ดำ/ขาว:** ปุ่มมุมบนขวา หรือสวิตช์ "มาตรฐาน / ขนส่ง / มืด" บนแผนที่ สลับทั้งหน้าเว็บและสีแผนที่ (พาเลตต์ Google Maps สว่าง/มืด) จำค่าไว้ใน localStorage (`bustime.theme`)
- **คู่มือการใช้งาน:** แท็บ “คู่มือ” 4 หัวข้อ (วางแผนเส้นทาง, ดูข้อมูลสถานี/สาย, แผนที่และธีม, ETA)
- **แอดมิน → รถไฟฟ้า:** เพิ่ม/แก้ไข/ลบสถานีและสาย (ชื่อ พิกัด เลือกพิกัดจากแผนที่ สีสาย ความถี่ และเลือกว่าสถานีอยู่สายไหน/ต่อจากสถานีใด) ข้อมูลเก็บใน `bustime.data.v4` (ย้ายสายรถเมล์จาก v3 อัตโนมัติ)

## แผนที่เวกเตอร์ประเทศไทยสไตล์ Google Maps (Standalone)

- **ไม่ดึง Tile ภายนอก:** วาดด้วย SVG/Canvas ผ่าน Leaflet (ซูม/แพนลื่น) ไม่มี API key ไม่มี Error 403 ทำงานออฟไลน์ได้ (ทดสอบเปิด `bustime-offline.html` ขณะตัดเน็ต: 0 คำขอ, 0 error)
- **พาเลตต์ Google Maps:** สว่าง — แผ่นดิน `#F8F9FA` น้ำ `#AADAFF` สวน `#CEEAD6` ถนนหลัก `#FCD34D/#F59E0B` ถนนรองขาวขอบ `#DADCE0` · มืด — แผ่นดิน `#242F3E` น้ำ `#17263C` ถนนหลัก `#746855` ถนนรอง `#38414E`
- **รายละเอียดทีละระดับซูม (Progressive Detail):** ซูมไกลเห็นประเทศ/ภาค/จังหวัด ทะเล แม่น้ำสายหลัก → ซูมกรุงเทพฯ เห็นถนนสายหลัก (เพชรเกษม บรมราชชนนี พระราม 2 สุขุมวิท พหลโยธิน ฯลฯ) แม่น้ำเจ้าพระยากว้างตามซูม สวนสาธารณะ ชื่อเขต ป้ายชื่อจัดวางแบบไม่ทับกัน
- **ชั้นขนส่ง (Transit Layer):** เส้นรถไฟฟ้า BTS/MRT/ARL/SRT สีประจำสาย วงแหวนสถานีเชื่อมต่อ ป้ายชื่อสถานีแบบ pill ปรับตามซูมและตัดป้ายที่ทับกัน · ป้ายรถเมล์เป็นหมุดสี่เหลี่ยมมนสีน้ำเงินรูปรถเมล์ คลิกเปิดการ์ดข้อมูล (สายที่ผ่าน + ETA)
- **ตัวควบคุม:** ช่องค้นหาลอยมุมซ้ายบน (สถานี/ป้าย/สาย) + ปุ่ม Directions เปิดการ์ดต้นทาง-ปลายทางพร้อมสลับและผลลัพธ์ · สวิตช์มุมมอง มาตรฐาน / ขนส่ง (เน้นเส้นทาง จางพื้นหลัง) / มืด · ซูม +/−, กลับฝั่งธนบุรี, ตำแหน่งของฉัน มุมขวาล่าง
- **ล็อกเฉพาะประเทศไทย:** `maxBounds [[5.5,97.3],[20.5,105.7]]`, `maxBoundsViscosity:1.0`, `minZoom:6`, `maxZoom:19`, `preferCanvas:true`; กล้องเลื่อนนุ่มด้วย `flyTo`/`flyToBounds`
- ลิงก์ “เปิดใน Google Maps” (`google.com/maps/dir|search` แบบไม่ใช้ API Key) ที่สถานี/ผลวางแผน — การฝัง Google Maps จริงต้องใช้ API Key + บัตรเครดิต จึงไม่ได้ใช้

## ข้อจำกัดที่ควรรู้ (ตรงไปตรงมา)
0. **ชุดข้อมูลฝั่งธนบุรี:** สาย 80 (4-43), 84 (4-46), 7 (4-36), 101 (4-5), 147 (4-25), 509 (4-60) + ป้ายโซนหนองแขม/บางแค/ท่าพระ–วงเวียนใหญ่ (รวมกับสายตัวอย่างเดิมอีก 8 สาย = 14 สาย) ค้นหา "บางแค", "หนองแขม", "สาย 80", "4-43", "ฝั่งธนบุรี" หรือชื่อป้าย จะกรองรายการและซูมแผนที่ไปยังผลลัพธ์ สาย 147 เป็นสายวงกลม แต่แอปวาดเป็นเส้นทางไป–กลับ ข้อมูลเก็บใน localStorage คีย์ `bustime.data.v3` (ข้อมูลเดิม v2 จะไม่ถูกนำมาใช้)
1. **ข้อมูลสาย/ป้าย/ตำแหน่งรถเป็นข้อมูลตัวอย่างและตัวจำลอง** ไม่ใช่ข้อมูลจริง – พิกัดป้ายเป็นค่าประมาณจากสถานีรถไฟฟ้า/จุดสำคัญ ไม่ใช่ป้าย ขสมก. จริง ลำดับป้ายของสาย 515 และ 73 เป็นตัวอย่าง และยังไม่มี API เรียลไทม์รถเมล์กรุงเทพฯแบบเปิดให้ใช้ ต้องต่อแหล่งข้อมูลจริง (เช่น GTFS / GTFS-Realtime) ที่ `loadData()` และ `simulate()` ใน `bustime.html`
2. เส้นทางตามถนนใช้โปรไฟล์ "รถยนต์" ของ OSRM จึงไม่รู้เรื่องเลนรถเมล์/ทางด่วนเฉพาะสาย และขาไป-ขากลับใช้เส้นเดียวกัน
3. ข้อมูลแอดมินในเบราว์เซอร์ (เวอร์ชันเว็บล้วน) เก็บใน localStorage ของเครื่องนั้นเท่านั้น และการล็อกอินฝั่งเบราว์เซอร์ไม่ใช่ความปลอดภัยระดับเซิร์ฟเวอร์ – ถ้าจะใช้งานจริงหลายเครื่อง ควรมี backend ที่ตรวจสิทธิ์
4. ยังไม่ได้รัน Electron จริงบน Windows ในสภาพแวดล้อมที่ผมทดสอบ (ทดสอบตรรกะ main/system ด้วย mock, และทดสอบ bundle Desktop ใน Chromium)
5. **ข้อมูลรถไฟฟ้า:** รายชื่อ ลำดับ และพิกัดสถานีมาจากความรู้ทั่วไป ไม่ได้ดึงจากแหล่งทางการ (ดึงข้อมูลออนไลน์ไม่ได้ในสภาพแวดล้อมที่สร้าง) จึงอาจคลาดเคลื่อนหรือไม่ครบ โดยเฉพาะสายสีเหลือง สีชมพู สีแดง และช่วงเหนือของสายสุขุมวิท (คูคต) โปรดตรวจกับข้อมูลทางการ/GTFS แล้วแก้ในแท็บแอดมิน เวลาขบวนถัดไปและเวลาเดินทางของตัววางแผนเป็นค่าประมาณจากความถี่/ความเร็วเฉลี่ย ไม่ใช่ตารางเดินรถจริง ไม่มีการคำนวณค่าโดยสาร
6. **ความละเอียดของแผนที่เวกเตอร์:** ไม่ใช่แผนที่ระดับ Google Maps จริง — ไม่มีรูปอาคาร/ซอยย่อย/ชื่อสถานที่เชิงพาณิชย์ ถนนสายหลักและสวนสาธารณะในกรุงเทพฯ ถูกเขียนมือจากพิกัดโดยประมาณ (เส้นอาจเยื้องจากถนนจริงบางช่วง) ส่วนถนน/แม่น้ำนอกกรุงเทพฯ มาจาก Natural Earth (ความละเอียด 1:10 ล้าน) ถ้าต้องการถนนระดับซอยต้องนำข้อมูล OSM extract ของประเทศไทยมาแปลงเป็นเวกเตอร์เพิ่ม
